1 · Hero (2 колонки)

EquinoxOS — монолитное ядро для x86_64 на C и ASM. Грузится через Limine, имеет композитный оконный менеджер с тенями и z-порядком, настоящую вытесняющую многозадачность, две файловые системы (FAT32 + EXT2), полный стек TCP/IP, звук AC97 — и портированный DOOM.

2 · Сетка фич (3 колонки)

4-уровневая страничная память

Bitmap PMM, отдельный PML4 на процесс, 64 МБ kernel heap, shared memory через shm_alloc.

Вытесняющая многозадачность

Round-robin планировщик на IRQ0 (PIT 1 кГц). Ring 3 с изолированными адресными пространствами, ELF64-загрузчик.

10+ системных вызовов через int 0x80

Чтение/запись файлов, мышь, клавиатура, звук, сеть (DNS/HTTP), pipes, очереди сообщений, exec.

Композитный WM

VESA LFB, двойная буферизация, тени, z-порядок, программный курсор. Рабочий стол enGUI на Lua.

Стек TCP/IP

RTL8139 · ARP · IPv4 · ICMP · UDP · TCP 3-way handshake · резолв DNS · HTTP GET · NTP. Всё в ядре.

Запускает DOOM

Нативный ELF-порт работает в Ring 3, общается с ядром через ввод, фреймбуфер и звук.
